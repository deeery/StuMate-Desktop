1启动页：不再恢复上次标签页，固定落在「今日」

原逻辑是 AppPage.entries[Prefs.getLastTab().coerceIn(0, 2)] —— 记住上次停留的 非设置页。后果是「上次在便签，下次打开还是便签」，与「打开就看今天」的预期不符。

改动

// AppShell.kt
- var page by remember(initialPage) {
-     mutableStateOf(initialPage ?: AppPage.entries[Prefs.getLastTab().coerceIn(0, 2)])
- }
+ // 启动一律落在「今日」。
+ // 以前是恢复上次停留的标签页（`Prefs.getLastTab()`），结果「上次在便签，
+ // 下次打开还是便签」，与「打开就看今天」的预期不符，故改为固定开今日。
+ var page by remember(initialPage) { mutableStateOf(initialPage ?: AppPage.TODAY) }

// 侧栏点击不再记录落点
- onSelect = {
-     page = it
-     if (it != AppPage.SETTINGS) Prefs.setLastTab(it.ordinal)
- }
+ onSelect = { page = it }
顺带清理：lastTab 变成死代码，已一并删除 Prefs.getLastTab() / Prefs.setLastTab() 全项目只有 AppShell 这一个调用点， 改动后彻底没人用。留着的话，它上面「从设置页退出后仍会回到之前那个页面」的注释会变成误导， 所以连函数一起删了。settings.json 里残留的 "lastTab": 0 键不影响运行（已不再被读取）。

2最底层底板：#202020 → #141414

这里先澄清一处措辞：验收意见里的「上下」指的是层级的前后（z 序），不是屏幕的上下 —— 目标是最后面那一层底板，也就是把「今天的课」和「便签」两张卡片包围起来的那块颜色。

它在代码里就是 FluentColors.bg，浅色是 #F3F3F3、深色原本是 #202020。 全项目只有两处引用：

改动

// FluentTokens.kt · FluentDarkColors
- bg = Color(0xFF202020),
+ // 窗口最底层的那块底板 —— 也就是承载卡片、「最后面」的那一层。
+ // 按验收意见从 #202020 调深到 #141414：底板压暗后，叠在上面的
+ // 卡片（surface #2B2B2B）与侧栏（surface2 #272727）层次才拉得开。
+ // 注意：页头 [PageTopBar] 与它共用这个 token，所以页头会一起变深；
+ // 若想让页头保持浅一档，需要单独拆一个 token 出来。
+ bg = Color(0xFF141414),
层次关系（改后） 底板 #141414 → 侧栏 #272727 → 卡片 #2B2B2B， 三级由深到浅、逐层抬升，卡片「浮起来」的观感比改前明显。

3需要您确认的两点

① 页头跟着一起变深了 页头 PageTopBar 与底板共用 bg 这一个 token，所以它也从 #202020 变成了 #141414，页头与底板现在连成一片（靠下方那条 1px 分隔线区分）。 这符合「最后面那一层整体压暗」的理解，但如果您希望页头比底板浅一档（比如保持 #202020）， 说一声，我拆一个独立 token 出来即可。
② 只改了深色主题 参考色 #141414 是深色，因此只动了 FluentDarkColors.bg； 浅色主题的底板仍是 #F3F3F3（当前系统为深色，所以您看到的是深色那套）。 若浅色主题也要相应调整，请给一个浅色参考色。

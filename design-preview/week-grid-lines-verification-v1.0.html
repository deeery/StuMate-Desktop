结论：已实现，且实测到位 表格视图每个整点都有一条 1 像素横向描边线，把每一列切成一个个时间格。深色下用底板色 #141414（比卡片面 #2B2B2B 暗 23 级），浅色下同一 token 落在 #F3F3F3（比纯白卡片面浅 12 级，即「更白的线段」）。跨节的课程卡片会把线盖住， 不会出现「线从课程块中间穿过去」。

诚实说明：浅色下的对比度偏弱 浅色线 #F3F3F3 对纯白卡片面只差 12 级，落在斑马纹 #F9F9F9 上只差 6 级。 这是「比白面更白」这个约束的物理上限（白色已经是 255，没法再白），所以只能取浅灰。 1:1 下看得见，但确实比深色弱。若你希望浅色也醒目一点，把 timeLine 在浅色分支换成 #E8E8E8（对白面差 23 级、对斑马纹差 17 级）即可——见第 6 节待拍板项。

线位一致性

逐列扫描（周一 ~ 周日各取列中心），每列都命中同一组 y 坐标：

首条 y=142   末条 y=784   相邻间隔 = 53 px（= 1 小时）
周一  n=11  周二  n=11  周三  n=11  周四  n=11  周五  n=11  周六  n=14  周日  n=14

缺口全部来自课程卡片遮挡（例如周一「高等数学」占 2 格 → 缺 2 条；
周三「计算机网络」跨 09:00~11:00 → 缺 248 / 301 两条）。

n=11 的列表示有 2 条被课程卡片盖住，n=14 表示该列无课、14 条线全部可见。 各列的线位完全一致，不存在「有的列有线、有的列没有」。

5途中发现并修掉的一个回归

问题：刻度线从时间数字正中间穿过去，看着像「删除线」 纵轴刻度线原本是 c.outline（#3A3A3A），只比底色深 11 级，压在标签上几乎看不出来。 换成底板色 #141414 之后深了 23 级，而时间标签是垂直居中压在刻度线上的， 于是「08:00 / 09:00 / 10:00」全部被划了一道横线。

顺带把画线方式从 drawLine 换成 吸附到整像素的 drawRect：

为什么要吸附整像素 抗锯齿会把 1px 的线按小数部分摊到相邻两行、各占约一半浓度。这条线本来就只比底色深 20 来级， 摊薄一半就基本看不见了——实测恰好有一半的整点落在半像素位置上（例如渲染成 #272727 + #1D1D1D，其中 #272727 只比底色深 4 级，等于白画）。 改成 roundToInt() 吸附后，1 行就是实打实的 1 行：全部整点都是干净的 #141414 / #F3F3F3。

6代码改动

只动了一个文件：src/main/kotlin/com/example/classreminder/ui/fluent/WeekPage.kt 的 WeekGrid()，共 4 处。

① 新增描边色 —— 直接复用底板 token

    val lineColor = c.outline
+   // 时间格的描边线，用**底板色**（就是刚调深的那一层）：
+   //  · 深色下它是 #141414，比卡片面 (#2B2B2B) 暗 —— 每个整点把这一列切开，
+   //    格子底色本来和卡片面一模一样，不描边就是一大片，分不出节次；
+   //  · 浅色下它就是底板那层 #F3F3F3，比纯白卡片面更浅一档，即「更白的线段」。
+   // 直接复用 c.bg 而不是另立 token，是因为需求就是「和底板同色」；
+   // 哪天要让网格线与底板脱钩，这里换成独立 token 即可。
+   val timeLine = c.bg
    val zebraColor = if (c.isDark) Color(0x0AFFFFFF) else Color(0x06000000)

② 取坐标时吸附到整像素

+   /**
+    * 把「分钟 → 纵坐标（像素）」算出来后**吸附到整像素**，再交给 drawRect 画 1 像素高的实心块。
+    *
+    * 为什么不用 `drawLine(y = 小数)`：抗锯齿会把 1px 的线按小数部分摊到相邻两行上，
+    * 各占约一半浓度。而这条线本身只比底色深 20 来级，摊薄一半就基本看不出来了。
+    */
+   fun lineY(heightPx: Float, minute: Int): Float =
+       (heightPx * mapping.fractionOf(minute)).roundToInt().toFloat()

③ 纵轴刻度线改用同色（原来只画在轴宽内、且是 outline 色）

    marks.forEach { m ->
-       val y = size.height * mapping.fractionOf(m)
-       drawLine(lineColor, Offset(0f, y), Offset(size.width, y), 1f)
+       // 用 timeLine 而不是 lineColor：这条刻度线在视觉上
+       // 与右边横跨各列的网格线是**同一条线**，两段不同色会像画错了
+       drawRect(
+           color = timeLine,
+           topLeft = Offset(0f, lineY(size.height, m)),
+           size = Size(size.width, 1f)
+       )
    }

④ 每天列内逐格画线 + 标签垫底

    // 每天列：斑马纹之后、hover 之前
    bands.forEach { band -> ... }
+   // 每个整点拉一条横线，把这一列切成一个个时间格。
+   // 画在斑马纹之上、课程块之下（drawBehind 天然在内容之下），
+   // 于是跨节的课会把线盖住，不会出现「线穿过课程卡片」。
+   marks.forEach { m ->
+       drawRect(
+           color = timeLine,
+           topLeft = Offset(0f, lineY(size.height, m)),
+           size = Size(size.width, 1f)
+       )
+   }

    // 纵轴标签（第 5 节的回归修复）
    Text(
        TimeAxis.labelOf(m), fontSize = 10.5.sp, color = c.onSurfaceFaint,
-       modifier = Modifier.offset(y = y - 7.dp).padding(start = 8.dp)
+       modifier = Modifier
+           .offset(y = y - 7.dp)
+           // 给标签垫一层与卡片同色的底，让刻度线在文字处**断开**。
+           .background(c.surface)
+           .padding(start = 8.dp, end = 5.dp)
    )
顺带修的工具问题 tools/shoot_scenarios.py 里 -Dstumate.theme=dark 是写死的， 导致「浅色验收」只能绕过脚本手敲 java 命令。已改为读环境变量 STUMATE_THEME（默认仍是 dark，不改变既有调用行为）。本次浅色截图即用它产出。

#事项当前做法可选项
1 浅色线对比度偏弱（Δ12 / Δ6） 用底板色 #F3F3F3 换成 #E8E8E8 更醒目；或维持现状
2 纵轴刻度线也换成了底板色 与列内网格线统一 若希望刻度线保持原来的 outline，一行可回退
3 深色下斑马纹与课程卡片底色恰好都是 #333333 既有问题，本轮未动 是否要拉开（卡片面本可以用 surface3 的另一档）
4 重置密码 / 设备管理 / 修改昵称对话框 仍可点外部关闭 是否也统一传 dismissible = false（同登录框）
5 页头是否从底板 token 拆出来 与底板共用 c.bg，一起变深 如需页头保持浅一档，要单独拆 token

手动验收步骤

  1. 启动应用（或直接开 week 预览场景），进「课表」页。
  2. 确认右上角分段控件停在 表格（若在「列表」，切到「表格」）。
  3. 看纵轴每个整点右侧是否有一条横线横跨七天，且横线不穿过「08:00」这类数字。
  4. 找一门跨两节以上的课（如周一「高等数学」），确认横线没有从卡片中间穿过去。
  5. 设置 → 外观切浅色，重复第 3、4 步。

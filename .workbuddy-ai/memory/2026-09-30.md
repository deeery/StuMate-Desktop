### 改动

- `TodayPage.kt`：页头不再放动作按钮；「新建提醒」进「今天的课」卡片标题行，
  「添加便签」进「便签 · N 条」卡片标题行（两行同为 `start 16 / end 12 / top-bottom 8`）。

### 踩到的两个 Windows 坑

1. **无边框窗口不能用 `WindowPlacement.Maximized`**：那走的是 AWT 的 `MAXIMIZED_BOTH`，
   实测 2560×1440 全屏把底部任务栏一起盖住了。改成自己算 `workAreaOf()`
   （屏幕 bounds 减 `Toolkit.getScreenInsets`）再设 `WindowState.size/position`，
   还原时用事先存下的 `restorePosition/restoreSize`。
2. **`SetForegroundWindow` 会被前台锁拒掉**（返回成功但窗口没上来），
   导致截图截到压在它上面的浏览器、点击落到别的窗口。
   解法：`SetWindowPos(HWND_TOPMOST)` → `SetWindowPos(HWND_NOTOPMOST)` → `BringWindowToTop`。
   另外「最小化→还原」之后 Windows 会吃掉紧接着的第一次点击，所以 `click-win`
   会先往侧栏空白死区点一下「热身」。

### GitHub 授权报错（服务端侧配置问题）
用户点 GitHub 登录后浏览器报 `The redirect_uri is not associated with this application`。

`redirect_uri = https://deeer.online/api/stumate/v1/oauth/github/callback`。
